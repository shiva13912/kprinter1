## 4. WordPress Responsive Image (`srcset`) Variants Analysis

During analysis, 21 image URLs referenced in `srcset` attributes were flagged as missing from `images/`. Investigation confirmed that these are **standard automated WordPress thumbnail resizes**, not missing master imagery:
- Master `Color-Logo.png` is present (95.8 KB); responsive variants (`-300x79.png`, `-1024x271.png`, `-768x203.png`, `-600x159.png`) were omitted by the crawler because the full master was downloaded.
- Master `Kakatiya-Logo-RGB.png` is present (96.8 KB); responsive variants (`-300x67.png`, `-768x172.png`, `-600x135.png`) are omitted.
- Master `building.webp` is present (102.3 KB); responsive resizes (`-200x300.webp`, `-600x900.webp`) are omitted.
- Master `Bottom-Banner.png` is present (1.06 MB); responsive resizes (`-300x65.png`, `-1024x223.png`, `-768x167.png`, `-1536x335.png`) are omitted.

**Takeaway for Migration**: 100% of the high-resolution source master graphics exist in `images/`. The new build can generate optimal modern responsive WebP/AVIF images directly from these masters.
